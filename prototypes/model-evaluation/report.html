How to read this

Prefix/suffix move the fixed question around the unchanged instruction. State uses filter and post fields. Choice names the keep/hide answers. AB and BA reverse the meanings attached to neutral answer keys.

Direct questions rewrite each known rule into a hand-written diagnostic question; they are not a general solution for arbitrary user instructions.

Strictness only changes the threshold. Softmax normalization is not evidence of calibration, and temperature scaling cannot fix an incorrect ranking.

Private text and labels remain local. Held-out cases have not been scored. Standalone-page timing excludes extension integration, sustained scrolling, and peak memory.
